# FastAPI Lecture Demo

Небольшой работающий HTTP API для лекции об устройстве и использовании программных интерфейсов. Исходный код можно изучать и запускать прямо в браузере через **GitHub Codespaces** — без локальной установки Python.

[![Открыть в GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/DNKlyosov/fastapi-lecture-demo?quickstart=1)

## Начало работы — через браузер

1. Нажмите **Открыть в GitHub Codespaces** (либо `Code → Codespaces → Create codespace on main`).
2. GitHub подготовит Python-среду, установит зависимости и запустит Uvicorn на порту **8000**.
3. Откроется окно Swagger UI; если оно не открылось автоматически, перейдите во вкладку **Ports**, нажмите на ссылку напротив `8000` (корневой адрес перенаправляет на `/docs`).
4. В разделе **Устройства** раскройте нужную GET-операцию, затем нажмите **Try it out → Execute**.

Адрес порта Codespaces выглядит как `https://<имя-codespace>-8000.app.github.dev`. Он индивидуален для каждой сессии; **не подставляйте вместо него `localhost:8000` в браузере собственного компьютера**.

По умолчанию перенаправленный порт **приватный**. Не делайте его публичным без необходимости.

## Две основные операции

| Метод и путь | Что возвращает | Пример |
| --- | --- | --- |
| `GET /api/products` | Каталог из пяти устройств, `data` и `meta.total` | 200 OK |
| `GET /api/products/{product_id}` | Одно устройство по идентификатору | `GET /api/products/5` → 200 OK |

Дополнительные адреса: `/docs` — Swagger UI, `/openapi.json` — спецификация OpenAPI.

Для несуществующего устройства сервер отвечает **404**, а для неположительного или нечислового идентификатора — **422**. Методы изменения данных не реализованы.

Пример результата `GET /api/products/5`:

```json
{
  "id": 5,
  "name": "Relay Controller",
  "type": "controller",
  "status": "active",
  "price": 59.9,
  "tags": ["power"]
}
```

## Где находятся основные файлы

- `app/main.py` — исходный код API и пять учебных устройств;
- `.devcontainer/devcontainer.json` — конфигурация автоматической настройки Codespaces;
- `.devcontainer/install.sh` — установка библиотек в `.venv`;
- `.devcontainer/start.sh` — автоматический запуск сервера при открытии Codespace;
- `tests/test_api.py` — проверки ответов и ошибок.

## Запуск на собственном компьютере (необязательно)

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
python -m uvicorn app.main:app --reload --port 8000
```

После запуска откройте <http://127.0.0.1:8000/docs>.

Проверка:

```bash
python -m pytest -q
```

## Ограничения и безопасность

- Данные фиксированы и хранятся в памяти процесса; база данных не подключена.
- Нет авторизации и методов изменения состояния. В проекте нет API-ключей и секретов.
- Codespace и перенаправленный порт работают только пока среда запущена. Это среда разработки, не production-хостинг.
- Не выставляйте приватный порт в публичный доступ без понимания последствий.
- Для образовательного использования у каждого студента может быть собственный Codespace; условия доступности и квоты определяются его GitHub-планом.
