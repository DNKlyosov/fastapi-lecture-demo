Операции API

В Swagger UI доступны GET, POST, PUT, PATCH и DELETE. Создайте устройство через POST, затем нажмите «Обновить» — оно появится в таблице с новым ID.

Изменения хранятся в памяти сервера. Кнопка «Восстановить исходные данные» отменяет учебные изменения.
